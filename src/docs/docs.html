Authentication

Public Endpoints

POST /auth/pending No Auth

Create a pending user before payment

Request Body

"name": "John Doe",
"email": "john@example.com",
"password": "password123"

Response

"success": true,
"message": "User created successfully",
"pendingId": "60f3b3b3b3b3b3b3b3b3b3b3"
POST /auth/login No Auth

Login user

Request Body

"email": "john@example.com",
"password": "password123"

Response

"success": true,
"token": "eyJhbGciOiJIUzI1NiIs...",
"user": {
  "id": "60f3b3b3b3b3b3b3b3b3b3b3",
  "name": "John Doe",
  "email": "john@example.com",
  "role": "student"
}

Payment

POST /payment/create-checkout-session No Auth

Create Stripe checkout session for payment

Request Body

"planId": "60f3b3b3b3b3b3b3b3b3b3b3",
"pendingId": "60f3b3b3b3b3b3b3b3b3b3b4"

Response

"success": true,
"sessionId": "cs_test_12345",
"checkoutUrl": "https://checkout.stripe.com/c/pay/cs_test_12345"
POST /payment/webhook No Auth

Stripe webhook for handling payment events

Important: This endpoint requires raw body parsing. Stripe will send events to this URL.

Webhook Event

"id": "evt_1234567890",
"object": "event",
"type": "payment_intent.succeeded",
"data": {
  "object": {
    "id": "pi_1234567890",
    "amount": 2000,
    "currency": "usd"
  }
}

Response

"success": true,
"message": "Webhook received successfully",
"eventId": "evt_1234567890"

Data Models

User Model

{
  "_id": ObjectId,
  "name": String,
  "email": String,
  "password": String,
  "role": String, // "student" or "admin"
  "isActive": Boolean,
  "planId": ObjectId,
  "joinedClasses": [ObjectId],
  "createdAt": Date,
  "updatedAt": Date
}

Class Model

{
  "_id": ObjectId,
  "name": String,
  "description": String,
  "instructorId": ObjectId,
  "students": [ObjectId],
  "files": [{
    "_id": ObjectId,
    "filename": String,
    "path": String,
    "uploadedAt": Date
  }],
  "notes": [{
    "_id": ObjectId,
    "title": String,
    "content": String,
    "createdAt": Date
  }],
  "tasks": [{
    "_id": ObjectId,
    "title": String,
    "description": String,
    "dueDate": Date,
    "fileUrl": String,
    "submissions": [{
      "_id": ObjectId,
      "studentId": ObjectId,
      "fileUrl": String,
      "submittedAt": Date
    }]
  }],
  "videos": [{
    "_id": ObjectId,
    "title": String,
    "url": String,
    "uploadedAt": Date
  }],
  "createdAt": Date,
  "updatedAt": Date
}

Plan Model

{
  "_id": ObjectId,
  "name": String,
  "description": String,
  "price": Number,
  "duration": Number, // in months
  "features": [String],
  "isActive": Boolean,
  "createdAt": Date,
  "updatedAt": Date
}

Transaction Model

{
  "_id": ObjectId,
  "userId": ObjectId,
  "planId": ObjectId,
  "amount": Number,
  "currency": String,
  "status": String, // "pending", "completed", "failed"
  "transactionId": String,
  "paymentMethod": String,
  "createdAt": Date,
  "updatedAt": Date
}

Pending User Model

{
  "_id": ObjectId,
  "name": String,
  "email": String,
  "password": String,
  "planId": ObjectId,
  "paymentStatus": String, // "pending", "completed", "cancelled"
  "createdAt": Date,
  "updatedAt": Date
}
